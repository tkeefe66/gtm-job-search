# Rocket-Ship Watchlist (reference tier — flags, never auto-waives)

Companies on this list are **not** on the named rocket-ship list. Appearing here does
**not** waive any gate. When a posting comes from a company on this list, the analysis
should add one line — "on [source] (rank/score if known) — possible rocket-ship, confirm?" —
name the source, and then **run every hard gate straight** (level, comp, location, discipline)
exactly as normal. The watchlist is awareness, not approval.

Two things this list explicitly protects against:
1. **Stage-vs-comp reality.** Most of these are seed–Series B. Many do not yet have a
   VP Product / CPO seat that clears the $350K floor; a "founding PM" or "first product hire"
   at a 30-person company is still a level+comp fail no matter how hot the logo.
2. **Discipline wall still applies.** Infra / inference / chips / foundation-model / physical-AI
   companies on this list are behind Chad's discipline wall. Tag them, but never flag them as a fit.

**Discipline tags:**
- `APP` = application/platform-layer B2B software product (Chad's discipline — plausibly relevant)
- `WALL` = dev-infra, inference, GPU/chips, foundation models, robotics/physical AI, research infra (discipline wall — never a fit even if hot)
- `MIXED` = has an app-layer surface but core is infra/research (treat with caution; verify the specific seat)

**Stage tags:** seed / A / B / C+ / late (pre-IPO) — approximate, verify at analysis time.

**How to promote to the named list:** only Chad promotes. The bar is "I would genuinely trade
down in title to join *this company*." Being high on a talent-density or momentum index is not
that bar. If Chad says "add X to the named list," move it into target_profile.md.

## Quick decision reminder when a watchlist company appears

1. Flag it: "on [Paraform TDI #N / Harmonic Hot 25 Q3 2026] — possible rocket-ship, confirm?"
2. Check the discipline tag. `WALL` → discipline gate still fails; say so plainly.
3. Run level + comp + location straight. Early stage usually means the product seat
   and/or comp won't clear the bar — score it honestly, don't let the badge inflate it.
4. Only Chad promotes a company to the named list. Suggest it if warranted; never auto-promote.
